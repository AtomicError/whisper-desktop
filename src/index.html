Welcome to Whisper Desktop

A modern, high-performance desktop application designed to orchestrate Whisper.cpp AI speech recognition and multi-language translation on Linux.

Features out-of-the-box pre-compiled GPU acceleration backends, an integrated HuggingFace model downloader, advanced Whisper engine orchestration, 40+ language AI translations, and real-time subtitle generation.

Pre-Compiled Hardware Acceleration
Pre-compiled Standard CPU, Vulkan GPU, OpenVINO, and CUDA backends ready out of the box with instant 1-click switching and zero setup.
Official Model Hub & Downloader
Integrated 1-click model downloader for official GGML weights (Tiny to Large-v3 & Turbo) with real-time download progress and local storage management.
40+ Languages AI Translation & Subtitles
Translate speech into 40+ world languages and export SRT, VTT, TXT, LRC, CSV, JSON, and word-level Karaoke timing formats.
Sequential Batch Processing Queue
Orchestrate multi-file transcription with dynamic queue sorting, individual item controls, and live execution progress.
Advanced Engine Orchestration
Fine-tune Whisper decoding parameters, VAD thresholds, beam sizes, temperature fallbacks, initial prompts, and thread concurrency.
Real-Time Telemetry & Clean Logs
Monitor execution telemetry, RAM/GPU memory meters, and ANSI-cleansed live logs with automated clipboard sync.

DTW Timestamps --dtw
Enable token-level timestamps via Dynamic Time Warping. Automatically matches the DTW model to your selected model. Disables Flash Attention.
Threads Count -t
Number of processor threads to allocate for standard decoding.
Processors Count -p
Number of parallel processors to use (useful for multi-stream transcription).

Maximum context size in tokens. Set -1 to auto-manage contexts.

Maximum segment length in characters (0 for unlimited).

Process audio from this timestamp offset in milliseconds.
Segment Index Offset -on
Starting offset index for written subtitles.
Process Duration (ms) -d
Limit audio duration to process in milliseconds (0 for entire file).
Split on Word -sow
Force split segments strictly on word boundaries rather than token bounds.
Speaker Diarization -di
Enable speaker diarization for stereo audio — distinguish who spoke when.
Tiny Diarization -tdrz
Lightweight on-device speaker change detection (requires a tdrz model).
Best Candidates Count -bo
Number of best candidates to maintain during standard greedy sampling.
Beam Search Size -bs
Beam size used for Beam Search decoding (increases accuracy at speed cost).

Initial decoding temperature (lower values are highly deterministic).
Temperature Increment -tpi
Temperature increment step value on fallback runs.
Disable Temperature Fallback -nf
Prevent automatic temperature fallback during decoding (forces initial temperature).
