Threads Count
Number of CPU worker threads allocated for decoding.
Default: 4 Recommended: Match your physical core count (e.g. 4–8) for maximum speed.
Processors Count
Number of parallel audio decoder instances.
Default: 1 (standard single-file mode) Recommended: Increase (2–4) only when batch-transcribing multiple files.
Max Token Context
Maximum preceding token history passed to the decoder.
Default: -1 (automatic context window) When to change: Lower to 64–128 if the model loops or repeats the same sentence.
Max Segment Length
Maximum character count allowed per subtitle line.
Default: 0 (unlimited natural sentence pauses) Recommended for Video / Reels: 35–45 characters for readable subtitles.
Time Offset (ms)
Skip audio from the beginning up to this timestamp in milliseconds.
Default: 0 ms Example: Set to 30000 to skip a 30-second intro or podcast sponsor.
Process Duration (ms)
Process only a slice of audio in milliseconds starting from offset.
Default: 0 ms (processes full file) Example: Set to 60000 to quickly preview a 1-minute clip.
Split on Word
Forces subtitle line breaks strictly between full words rather than splitting in the middle of words.
Recommended: Enabled for clean, professional subtitles.
Speaker Diarization
Separates and labels speakers across stereo audio channels (Left vs Right channel).
Output tags: [SPEAKER 0] and [SPEAKER 1] Requirement: Requires 2-channel stereo audio.
Tiny Diarization
Detects speaker turn transitions within a single mono channel using specialized models.
Requirement: Requires tdrz-enabled models (e.g. small.en-tdrz).
Best Candidates Count
Number of candidate sequences sampled during decoding.
Default: 5 Recommendation: Higher (6–8) boosts accuracy; lower (1–2) runs faster.
Beam Search Size
Exploration beam width for finding optimal word sequences.
Default: 5 Trade-off: Higher values reduce word errors and hallucinations, but increase transcription time.
Audio Context Size
Audio frame context length in samples.
Default: 0 (uses model default 30-second context window) Advanced: Restricts attention window for custom streaming workflows.
Word Timestamp Threshold
Acoustic probability cutoff for locking individual word timestamps.
Default: 0.01 When to change: Increase (0.05–0.1) if word timings drift during silent parts.
Entropy Threshold
Decoder uncertainty cutoff for triggering temperature fallback retry.
Default: 2.4 When to change: Lower to 2.2 if model produces repetitive gibberish.
Log Probability Threshold
Average token confidence threshold before fallback decoding is triggered.
Default: -1 When to change: Lower to -1.5 for noisy or accented speech to prevent unnecessary retries.
No Speech Threshold
Silence detection probability cutoff to suppress hallucinated words.
Default: 0.6 When to change: Increase to 0.7–0.8 if Whisper hallucinates words during music or background noise.
Sampling Temperature
Controls decoding randomness and exploration.
Default: 0 (deterministic greedy decoding — highest precision) When to change: Set to 0.2–0.4 only if the model gets stuck in repetition loops.
Temperature Increment
Step size to increase temperature on each fallback retry.
Default: 0.2 Retry sequence: Automatically retries at 0.2, 0.4, 0.6, up to 1.0.
Disable Temperature Fallback
Skips retry passes with higher temperatures and accepts the first greedy pass.
Benefit: 30–50% faster processing on difficult or noisy files. Trade-off: Skips error recovery if speech is unclear.
Log Decoder Scores
Prints raw confidence and probability scores for each decoded token into the activity log stream.
Use case: Debugging model confidence, timestamp boundaries, and acoustic quality.

VAD Model
Active Silero VAD model binary.
Default: ggml-silero-v6.2.0.bin (auto-loaded from models directory)
VAD Threshold
Speech probability cutoff for triggering voice activity detection.
Default: 0.5 Noisy / Heavy Breathing: Set to 0.65–0.75 (stricter filter) Soft Whispers / Distant Mic: Set to 0.35–0.45 (more sensitive)
VAD Min Speech (ms)
Minimum continuous voice duration required to trigger transcription.
Default: 250 ms Purpose: Ignores brief clicks, coughs, and keystrokes shorter than this duration.
VAD Min Silence (ms)
Minimum silence duration required to split speech into a new subtitle segment.
Default: 100 ms Recommended for Subtitles: Increase to 300–500 ms for natural conversational pauses.
VAD Max Speech (ms)
Maximum continuous speech segment duration sent to Whisper in one chunk.
Default: 30,000 ms (30s) Purpose: Matches Whisper's acoustic window to prevent memory overflow.
VAD Speech Padding (ms)
Audio buffer added before and after each detected speech segment.
Default: 30 ms Purpose: Prevents clipping starting consonants or trailing syllables.
VAD Segment Overlap
Contextual overlap ratio between consecutive speech segments.
Default: 0.1 (10%) Purpose: Preserves grammatical continuity across segment boundaries.
