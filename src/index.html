Welcome to Whisper Desktop

This is a modern, high-performance desktop application designed exclusively for Linux to orchestrate and execute Whisper.cpp audio-to-text models.

Use this manager to download models, verify hardware acceleration dependencies, optimize custom computation settings, convert audio streams, and output multiple subtitle formats in real time.

Multi-Backend Compilation
Easily build Standard CPU, Vulkan, OpenVINO, and CUDA acceleration backends in one click.
Sequential Batch Queue
Orchestrate multi-file transcription with dynamic queue controls, precise duration tracking, individual item removal, and real-time progress.
Premium Glassmorphic CSD HUD
Enjoy a custom obsidian glassmorphic UI featuring GTK-style client-side decorations (CSD), fluid window dragging, and ambient telemetry.
Pristine Live Logging Viewport
Monitor execution events with spaced monospace category grids and clipboard synchronization with automated ANSI formatting sequence stripping.
Complete Whisper Management
Experience simplified settings control. Switch presets, tune Silero VAD, auto-probe media specifications, and export TXT, SRT, VTT, LRC, CSV, JSON, and karaoke subtitles.
Self-Healing Diagnostics HUD
Prevent GPU crashes with safe-clamped decoders, scan local directory for missing files, and rely on regex-based stderr duration fallbacks.
